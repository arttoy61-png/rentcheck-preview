지역 조건줄을 모바일 상단의 실제 독립 영역으로 옮겼습니다. 목록 패널 숨김/클리핑에 의존하지 않습니다. 처음 자료를 기다릴 때는 지역 준비 중으로 비활성 표시하고 준비 후 실제 지역 선택으로 전환됩니다.
지도 연결 안내는 설정에서 열며 기본 화면의 지도 찾기와 경계 버튼을 가리지 않습니다. 브랜드/검색/하단 SVG 아이콘, 84px 접힌 시트, 40×4px 손잡이, 214×42px 지도 찾기 버튼을 승인 시안 기준으로 보완했습니다.

실제 키 없는 Chrome 검수
- 모바일 390×844 상단 지역칩과 5개 지도탭, 목록·상세 상태에서 가시성 확인.
- PC932와 모바일 왕복 시 조건줄 위치와 선택지역 유지. 설정 펼침/접기 후 지도영역 높이와 조작버튼 복원.
- 별도 지연 검사 화면에서 처음 지역 준비중/disabled 표시 → 자료 시작 후26개 옵션 → 노원구 선택 → 재로드 후 노원 복원 확인. 공공주택 노원은 지역 확인1·자치구 미확인2로 구분합니다. 이 검사는 실제 사용자 네트워크 지연을 관측한 것이 아닙니다.

검증 한계
사용자 실폰에서 지역이 사라진 현상 자체는 Chrome에서 재현하지 못했습니다. 하단패널 안의 fixed 요소였던 구조와 준비 전 빈 UI를 개선한 것이며 실폰 원인을 확정한 것은 아닙니다. 새 버전 실제 Kakao SDK/실제 위치 권한/물리 iPhone은 미검증입니다. 캡처의 행정구역 보조지도는 실제 카카오 연결 화면이 아닙니다. 시안 예시의 지형·핀·경계를 실제 자료로 복사하지 않았습니다.

보존
운영홈과 원래v7을 변경하지 않았습니다. index.html은 승인된 초기 UI 마크업만 바뀌었습니다. 키입력 section, SDK를 포함한 기존 script태그, kakao-session.js, kakao-map-engine.js는 이전과 동일합니다. API키/자동연결 반환본 config는 포함하지 않습니다.
